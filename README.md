Multithreaded Server (Short-Lived Connections)

Overview

This project is a multithreaded server implementation in Java using ServerSocket. It is designed to handle multiple client connections concurrently, where each connection is short-lived—meaning the server processes the request and closes the connection immediately after responding.

The project demonstrates core concepts of network programming, concurrency, and thread management in Java.

Features
Handles multiple client connections simultaneously
Uses a thread-per-request model
Supports short-lived client-server communication
Lightweight and easy to extend
Demonstrates basic request-response lifecycle
